# دفتر الامتياز

الموقع الرسمي العربي لتطبيق **دفتر الامتياز**، وهو تطبيق لإدارة العملاء والموردين والصندوق والمصروفات والبيانات التشغيلية من واجهة هاتف عربية.

## الموقع

بعد نجاح النشر، يتاح الموقع على:

`https://eng-saqr-nabil.github.io/daftar-alimtiaz/`

## التطوير المحلي

يتطلب المشروع Node.js 22 وpnpm 10. لتشغيله محلياً:

```bash
pnpm install
pnpm dev
```

ولفحص المشروع وبناء نسخة الإنتاج:

```bash
pnpm check
pnpm build
```

## النشر

يُنشَر الموقع تلقائياً إلى GitHub Pages عند الدفع إلى فرع `main` عبر سير العمل الموجود في `.github/workflows/deploy-pages.yml`. تُحفظ أصول العلامة ولقطات التطبيق في إصدار GitHub باسم `site-assets` حتى تبقى ملفات الموقع خفيفة وقابلة للتحميل من GitHub Pages.

## ملف APK

لا يتضمن المستودع ملف APK حالياً. عند اعتماد النسخة الرسمية، سيُرفع الاسم الثابت `daftar-alimtiaz.apk` إلى GitHub Release منفصل، وستُحدَّث جميع أزرار التنزيل بالرابط المباشر للإصدار الأخير.

## الحقوق

جميع الشعار ولقطات واجهة التطبيق المعروضة هنا هي أصول قدمها مالك تطبيق دفتر الامتياز لاستخدامها في الموقع الرسمي.
